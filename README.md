# Internet-Relay-Printer

this is a project using a rongta rp326, a raspberry Pi 5 and some power providing jank to be able to have a recept printer have a live feed of an IRC channel or any terminal application

the commands on the pi are 

- script -f /dev/usb/lp0
- export PROMPT_COMMAND='echo "\n\n\n\n\n\n\n"'
